À propos

Cette page présente le contexte du projet et l’objectif du site vitrine. Le but est de proposer une navigation simple, un style cohérent, et des contenus clairs.

Contexte du projet

Ce site a été réalisé dans le cadre du module Web XTI205. Il met en pratique les bases du HTML et du CSS : structure, mise en page, typographie, organisation des fichiers et cohérence graphique.

Objectifs

  • Créer un site multi-pages avec une navigation fonctionnelle.
  • Utiliser une feuille de style CSS commune à toutes les pages.
  • Proposer une interface lisible et harmonieuse (titres, blocs, footer).
  • Respecter les bonnes pratiques (sémantique HTML, organisation, responsive simple).

Technologies utilisées

  • HTML5 (structure des pages)
  • CSS3 (mise en page + style commun)
  • Images (illustration et identité visuelle)
